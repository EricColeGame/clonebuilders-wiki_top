## How the Clone Building Loop Works

The core loop is described in one sentence: give your clones an idea, and they build. In practice, that means the interesting part is not clicking parts together yourself. It is translating a goal into a form the clone system can act on, then watching how the clones interpret it.

The building system is described as structured, which is the key detail. Clones place parts, resize them, move them, and assemble them. That is a placement-and-assembly pipeline rather than freeform sculpting. If you have used other NPC builder experiences, the mental model is similar: you are directing, and the clones are executing within a defined set of allowed actions.

## Why Private Servers Are Recommended

The official description recommends a private server for large builds or minigames, and the reasoning is practical rather than mysterious. With up to 15 players per server, a public session can get crowded. Multiple players directing clones at once means more parts, more movement, and more visual noise. If your goal is a big structure or a small game built inside the sandbox, a private server removes that interference.

This is one of the few pieces of concrete advice the developers give, so it is worth taking at face value. It also tells you something about intent: the experience is designed to support player-made minigames, not just single structures. The official page does not list example minigames, so if you want ideas, the best source is other players in a live server rather than a written list.
